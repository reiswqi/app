## Architecture
- État `S` dans localStorage clé `ta10` ; état de vue `V` ; `render()` reconstruit `#app` ; délégation de clics sur `[data-a]` ; routeur par hash (`#programmes`, `#priere`, `#bonus`, `#guide`, `#nombres`, `#focus`, `#saint-antoine`) ; overlays `#unlock` (bravo/débloqué) et `.scrim.low .sheet` (modales).
- Onglets : Accueil, Programmes (rails : Mes programmes, Prières de Saint Antoine, **Pratiques divines** = Nombres Puissants + Focus du Jour, À découvrir), Prières Quotidiennes, Bonus (thème du mois), Père Michel (chat ; sur GitHub il n'y a que des réponses de secours).
- Tokens : fond #0a1426, accent doré #dcc084, émeraude #149364/#07583a, carte #1d3252, polices Cormorant Garamond + Lato.
- Thème du mois (Bonus) : change tout seul selon le mois du visiteur (`THEMES[NOW.getMonth()]`). `THEME_PAGE` a le contenu complet de novembre (mois 10) : sous-titre, intro, « ce que vous apprendrez », 5 épisodes « Écritures Vivantes », et `vid` = lecteur `<video>` natif (`video/aulaN.mp4`, poster `img/aulaN.jpg` = image tirée de la vidéo, sans sous-titres), `hero` (couverture `img/theme-nov.jpg`), `dur` (durées). Design « chamativo » : grande couverture + bouton doré Commencer/Continuer, barre de progression, cartes de leçons avec miniature, durée et badge « Vue » ; leçon vue à 90 % (`S.tw[année-mois]`, `epTick`) ; carte image dans Bonus (`themeCard`). Les autres mois affichent « Bientôt » tant que le contenu n'est pas ajouté ; une entrée `vid` qui n'est pas `video/...` est lue comme ID Google Drive (ancien iframe, déconseillé : barre noire + bouton Drive).
- Remboursement (`vRefund`, onglet « Rembourser », bannière rouge à l'Accueil, carte « Assistance » dans Programmes, lien `#remboursement`) : procédure en 3 étapes inspirée de la page refund.html de l'app anglaise (même déroulé, textes français originaux) : e-mail → motif (6 choix + précisions) → confirmation (« acte de foi », case à cocher) → traitement → succès. Demande gardée dans `S.refund`. `REFUND_HOOK` = FormSubmit (`https://formsubmit.co/ajax/lr.bussine@gmail.com`) : chaque demande arrive par e-mail à Lucas (tableau : nom, e-mails, motif, précisions, date, jour). Au 1er envoi, FormSubmit envoie un e-mail d'activation à cliquer ; ensuite, remplacer l'adresse par le code aléatoire fourni pour la cacher. `SUPPORT` = contact@app-parcoursdefoi.online (redirection Railway → lr.bussine@gmail.com), e-mail d'aide affiché partout (connexion, succès du remboursement, réponses du Père Michel).
- Journal d'activité + admin (serveur **Railway** + Postgres Railway, plus Supabase) : `src.html` envoie chaque action (`track(type,detail)` : open, login+consentement, view, act = clics `data-a`, video, priere, lecon, cadeau, chat (longueur seulement), refund, away (secondes actives), back, error) en `text/plain` vers `API_URL/api/events` (file d'attente `ta_q`, appareil `ta_dev`). Serveur `server/index.js` (racine : `package.json`, `railway.json`, démarrage `node server/index.js`, `/health`) : crée la table au démarrage (`server/schema.sql`), ajoute heure serveur, IP (`x-real-ip` / dernier `x-forwarded-for`, + `ip_chain`) et pays (geoip-lite) ; déclencheurs qui interdisent toute modification/suppression. Panneau `admin.html` servi par le serveur sur `/admin` (portugais, mot de passe `ADMIN_PASSWORD`, jeton HMAC 12 h signé avec `ADMIN_SECRET`, 8 essais/15 min) : clients, activité récente, remboursements, fiche client (consentement, appareils, IP/pays, contenus, chronologie), CSV, « Imprimir dossiê / PDF ». Sur GitHub Pages, admin.html redirige vers `ADMIN_URL`. Variables Railway du service « app » : `DATABASE_URL` = référence `${{Postgres.DATABASE_URL}}`, `ADMIN_PASSWORD` (`ADMIN_SECRET` facultatif : sinon dérivé de DATABASE_URL). Domaine Railway : https://app-production-b4b778ce.up.railway.app (`API_URL` dans src.html, `ADMIN_URL` = …/admin dans admin.html ; port 8080). Claude a un jeton de projet Railway (en-tête `Project-Access-Token`, injecté par le proxy pour backboard.railway.com) : API GraphQL `https://backboard.railway.com/graphql/v2` (projet b3535745-fd55-4e04-8d19-ee3ddc94b731, env production d6a17d8b-453e-42c8-b9ec-c48b2d6e297f, service app c18e892d-b51f-47df-aa81-a12776b1d312, Postgres 8338a617-7abf-4578-9185-fb312539ce42). Chaque push sur `main` redéploie le service app. Le serveur sert aussi l'app (`/` = temps-abondance.html, `/img/*`, `/video/*` avec Range ; rien d'autre du dépôt) : domaine personnalisé **app-parcoursdefoi.online** ajouté au service app (acheté dans Railway, DNS géré par Railway, vérifié et en ligne, https OK). L'admin y est sur `/admin`. Le lien GitHub Pages reste valable. Écran de connexion : petite phrase discrète sans lien « En continuant, vous acceptez nos conditions d'utilisation et notre politique de confidentialité » (Lucas : les textes sont déjà sur la page de vente) ; les textes complets restent accessibles dans le menu du compte (`openLegal('cgu'|'conf')`, `LEGAL`). `CONSENT_V='2026-11-v2'` (v1 = ancienne phrase « votre activité… soit enregistrée ») ; l'admin affiche la version acceptée et le texte correspondant (`CONSENT_TXT`). Textes rédigés par Claude : à faire relire par un juriste ; mentions légales de l'éditeur (identité, adresse) à ajouter quand Lucas les donnera. Test local : Postgres 16 dans le conteneur (initdb dans /var/tmp, port 5433).
- Comptes clients avec mot de passe : écran de connexion par étapes (`L.s` : mail → new (nom + mot de passe, on entre tout de suite) / pass / forgot / temp ; `local` = ancien écran sans serveur). API `/api/auth/check|register|login|password` (corps en text/plain, scrypt salé, limites d'essais), table `users`, jeton client `uid.date.sig` gardé dans `S.tok` (reste connecté). Les actions envoyées avec `{tok, ev}` sont rattachées au compte (`events.uid`, `verified`) ; le serveur écrit register / login_ok / login_fail / password_set / reset_admin. Admin : bloc « Conta com senha », badge « conta ✓ », bouton « Gerar senha temporária » (POST /api/admin/reset) → le client choisit un nouveau mot de passe au login. Anciens clients sans mot de passe : écran de connexion avec e-mail pré-rempli. Lien personnel `?e=adresse` (pour les e-mails envoyés aux clients) : e-mail rempli, étape « Créez votre accès » ou mot de passe directement, paramètre effacé de la barre d'adresse. Hors ligne : on entre sans compte (`V.offline`).
- Ventes **KashPay** (Stripe ; Lucas n'utilise pas Kiwify) : webhook `POST /api/webhooks/kashpay` (doc https://app.kashpay.com.br/docs/webhooks ; signature `X-KashPay-Signature: sha256=HMAC(secret, corps brut)` vérifiée avec `KASHPAY_WEBHOOK_SECRET`, sinon 401/503), table `purchases` (unique event+kp_id, payload brut gardé). `accessOf(email)` : payé / bloqué (remboursé ou chargeback). Inscription et connexion refusées si bloqué ; `/api/auth/me` à l'ouverture de l'app → déconnexion automatique avec message. `ACCESS_MODE` = open (défaut) | buyers (seuls les acheteurs créent un compte ; les comptes existants continuent). Admin : onglet « Vendas » (état du webhook, URL à coller, ventes, « nunca entrou no app »), bloc « Compras (KashPay) » et achats dans la chronologie du dossier, badges pago/reembolsado/CHARGEBACK, bouton « Liberar acesso manualmente » (`manual.grant`) + champ « Liberar acesso manualmente » dans Vendas pour coller une liste d'e-mails (POST /api/admin/grant {emails}, jusqu'à 5000, ignore ceux qui ont déjà accès).

## Règles de travail
- Dans le Chromium de test, Cormorant affiche les accents décalés (coût, contrôle) : bug d'affichage de l'environnement, pas des textes (déjà en NFC).
- `src.html` doit garder en tête `<meta charset="utf-8">` et `<meta name="viewport" content="width=device-width, initial-scale=1, viewport-fit=cover">` : sans elles, l'iPhone affiche la page en 980 px (tout minuscule). Tester aussi avec `devices['iPhone 13']` dans Playwright. `html,body{margin:0}` est obligatoire (sinon 8 px de marge du navigateur = trou en bas à gauche) ; la barre d'onglets a un fond pleine largeur (`nav.tabs::before`) pour tablette/ordinateur. Tester iPhone, Pixel, iPad et 1366 px.
- Ne jamais copier le texte d'autres apps : contenu original. Tester en 400 px (Playwright) avant de publier. Vérifier les accents français.
- Pousser sur `main` directement, sauf demande contraire. Ne jamais écrire de token dans un fichier.
- Les fichiers > 100 Mo ne passent pas sur GitHub : compresser les vidéos (ffmpeg, 540p, crf 29).
