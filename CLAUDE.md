# Temps d'Abondance — contexte du projet (à lire d'abord)

Lucas (Brésil, parle portugais avec Claude) reconstruit l'app française « Temps d'Abondance » : application web mobile premium, minimaliste, gamifiée. **Toute l'interface est en français** ; avec Lucas on parle en portugais (BR), ton chaleureux, réponses courtes, sans jargon.

## Où est le code
- Dépôt : `reiswqi/app` (public, GitHub Pages sur `main`). App en ligne : https://reiswqi.github.io/app/temps-abondance.html (le lien doit rester exactement celui-ci).
- `src.html` = source (SPA JS vanilla en un seul fichier, marqueur `__DAILY__`). **On édite src.html puis on lance `python3 build.py`** qui lit `prieres.json` (104 prières) et écrit `temps-abondance.html`. Toujours commit : src.html + temps-abondance.html (+ img/, video/).
- `img/` : couvertures (ange, michel, chant, freq, salomon, promesses, pere, sa1–sa5, nombres, focus, aula1–5). `video/aula1–5.mp4` : leçons du thème de novembre (540p, ~8–11 Mo chacune).

## Architecture
- État `S` dans localStorage clé `ta10` ; état de vue `V` ; `render()` reconstruit `#app` ; délégation de clics sur `[data-a]` ; routeur par hash (`#programmes`, `#priere`, `#bonus`, `#guide`, `#nombres`, `#focus`, `#saint-antoine`) ; overlays `#unlock` (bravo/débloqué) et `.scrim.low .sheet` (modales).
- Onglets : Accueil, Programmes (rails : Mes programmes, Prières de Saint Antoine, **Pratiques divines** = Nombres Puissants + Focus du Jour, À découvrir), Prières Quotidiennes, Bonus (thème du mois), Père Michel (chat ; sur GitHub il n'y a que des réponses de secours).
- Tokens : fond #0a1426, accent doré #dcc084, émeraude #149364/#07583a, carte #1d3252, polices Cormorant Garamond + Lato.
- Thème du mois (Bonus) : change tout seul selon le mois du visiteur (`THEMES[NOW.getMonth()]`). `THEME_PAGE` a le contenu complet de novembre (mois 10) : sous-titre, intro, « ce que vous apprendrez », 5 épisodes « Écritures Vivantes », et `vid` = lecteur `<video>` natif (`video/aulaN.mp4`, poster `img/aulaN.jpg` = image tirée de la vidéo, sans sous-titres), `hero` (couverture `img/theme-nov.jpg`), `dur` (durées). Design « chamativo » : grande couverture + bouton doré Commencer/Continuer, barre de progression, cartes de leçons avec miniature, durée et badge « Vue » ; leçon vue à 90 % (`S.tw[année-mois]`, `epTick`) ; carte image dans Bonus (`themeCard`). Les autres mois affichent « Bientôt » tant que le contenu n'est pas ajouté ; une entrée `vid` qui n'est pas `video/...` est lue comme ID Google Drive (ancien iframe, déconseillé : barre noire + bouton Drive).
- Remboursement (`vRefund`, onglet « Rembourser », bannière rouge à l'Accueil, carte « Assistance » dans Programmes, lien `#remboursement`) : procédure en 3 étapes inspirée de la page refund.html de l'app anglaise (même déroulé, textes français originaux) : e-mail → motif (6 choix + précisions) → confirmation (« acte de foi », case à cocher) → traitement → succès. Demande gardée dans `S.refund`. `REFUND_HOOK` = FormSubmit (`https://formsubmit.co/ajax/lr.bussine@gmail.com`) : chaque demande arrive par e-mail à Lucas (tableau : nom, e-mails, motif, précisions, date, jour). Au 1er envoi, FormSubmit envoie un e-mail d'activation à cliquer ; ensuite, remplacer l'adresse par le code aléatoire fourni pour la cacher. `SUPPORT` = lr.bussine@gmail.com, e-mail d'aide affiché partout (connexion, succès du remboursement, réponses du Père Michel).
- Journal d'activité + admin (serveur **Railway** + Postgres Railway, plus Supabase) : `src.html` envoie chaque action (`track(type,detail)` : open, login+consentement, view, act = clics `data-a`, video, priere, lecon, cadeau, chat (longueur seulement), refund, away (secondes actives), back, error) en `text/plain` vers `API_URL/api/events` (file d'attente `ta_q`, appareil `ta_dev`). Serveur `server/index.js` (racine : `package.json`, `railway.json`, démarrage `node server/index.js`, `/health`) : crée la table au démarrage (`server/schema.sql`), ajoute heure serveur, IP (`x-real-ip` / dernier `x-forwarded-for`, + `ip_chain`) et pays (geoip-lite) ; déclencheurs qui interdisent toute modification/suppression. Panneau `admin.html` servi par le serveur sur `/admin` (portugais, mot de passe `ADMIN_PASSWORD`, jeton HMAC 12 h signé avec `ADMIN_SECRET`, 8 essais/15 min) : clients, activité récente, remboursements, fiche client (consentement, appareils, IP/pays, contenus, chronologie), CSV, « Imprimir dossiê / PDF ». Sur GitHub Pages, admin.html redirige vers `ADMIN_URL`. Variables Railway du service « app » : `DATABASE_URL` = référence `${{Postgres.DATABASE_URL}}`, `ADMIN_PASSWORD`, `ADMIN_SECRET`. **`API_URL` (src.html) et `ADMIN_URL` (admin.html) sont vides** tant que Lucas n'a pas généré le domaine Railway. Mention de consentement sur l'écran de connexion (`CONSENT_V`). Test local : Postgres 16 dans le conteneur (initdb dans /var/tmp, port 5433).
- Nombres Puissants (S.nm) : Oracle / Horloge / Mon nombre ; 3 étapes → pop-up « Cadeau débloqué ». Focus du Jour (S.fc) : un thème par jour, 3 intentions ou la sienne, pop-up « Bravo », série de jours. Textes originaux de Claude : **les versets sont à vérifier**.

## Règles de travail
- Dans le Chromium de test, Cormorant affiche les accents décalés (coût, contrôle) : bug d'affichage de l'environnement, pas des textes (déjà en NFC).
- `src.html` doit garder en tête `<meta charset="utf-8">` et `<meta name="viewport" content="width=device-width, initial-scale=1, viewport-fit=cover">` : sans elles, l'iPhone affiche la page en 980 px (tout minuscule). Tester aussi avec `devices['iPhone 13']` dans Playwright. `html,body{margin:0}` est obligatoire (sinon 8 px de marge du navigateur = trou en bas à gauche) ; la barre d'onglets a un fond pleine largeur (`nav.tabs::before`) pour tablette/ordinateur. Tester iPhone, Pixel, iPad et 1366 px.
- Ne jamais copier le texte d'autres apps : contenu original. Tester en 400 px (Playwright) avant de publier. Vérifier les accents français.
- Pousser sur `main` directement, sauf demande contraire. Ne jamais écrire de token dans un fichier.
- Les fichiers > 100 Mo ne passent pas sur GitHub : compresser les vidéos (ffmpeg, 540p, crf 29).
